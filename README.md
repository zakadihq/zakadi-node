# zakadi-node

Server-side client for the Zakadi API for Node.js 20+: session creation, results, evidence, webhook signature verification and result-token verification. Specification: `zakadi/spec/02-api.md` section 2.11. The Python twin is `zakadi-python`.

Status: not yet started; the specification lives in the `zakadi` repository.
